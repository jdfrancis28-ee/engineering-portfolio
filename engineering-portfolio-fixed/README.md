# Jacob Francis — Engineering Portfolio

Dark, recruiter-facing electrical engineering portfolio focused on FPGA/RTL, embedded systems, circuit design, signal processing, and hardware security.

## Local preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

In this repository, go to **Settings → Pages → Build and deployment → Source → Deploy from a branch**. Choose `main` and `/ (root)`, then save.

The site will publish at:

`https://jdfrancis28-ee.github.io/engineering-portfolio/`
